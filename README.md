This repo is used for the graphics in the Illinois Answers story [City Leaders Tout Tree-Planting Bonanza, But Neighborhood Disparities Persist](https://illinoisanswers.org/2026/06/26/city-leaders-tout-tree-planting-bonanza-but-neighborhood-disparities-persist/). 

We would love for you to republish the story following our [republishing guidelines](https://illinoisanswers.org/content-republishing-guidelines/) and use as many of the graphics as you can. We can also provide the photos and video we used in the story (just email me -- aadams@bettergov.org -- and I'll send a link) 

In order of appearance, the code we used for the graphics are: 

[Tree Lookup Tool](tree_interactive.html) 
  
[Scrolling maps](chicago_trees_scrolly_embed.html)
  
[Tree animation](tree_animation.html)
  
[Wait times map](waitTimesEmbed.html)

Please note that the wait times map has its original code as a complete HTML document because it was designed to be embedded as an iframe and the code we used for the iframe is what's referenced above. You may need to modify the iframe height. The other graphics may require some trial and error. They work well on WordPress sites as Custom HTML blocks but your mileage may vary. Please reach out if you have issues.
